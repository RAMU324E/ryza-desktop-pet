## 三、口型同步 —— 官方方案（零猜测，参数全给）

**结论：客户端实时 RMS 能量驱动，无服务端口型数据**（WS 抓包 285 帧确认 audio 帧不带 lipsync 字段）。

`projectConfig.lipSyncClosure`（enabled: true）：
```
rmsCeiling: 1.0          opennessFloorDb: -40     opennessCeilingDb: -3
opennessOutputScale: 1.0 opennessAttackMs: 20     opennessReleaseMs: 60
crossfadeMs: 60          minHoldMs: 50            dipThreshold: 0.1
refWindowMs: 500         ratio: 0.1
```
实现：音频 RMS → dB → [-40, -3] 映射到开嘴度 → 20ms attack / 60ms release 平滑 → 驱动 `face_mouth_top/btm`（或 scrub facial_mouth_001~034 动画时间轴）。

## 附：情感 → 表现速查（LLM 标签怎么用）

WS 抓包 segment 帧格式：`@ライザ:[emotion:happy_normal][attitude:idle][tension:0.50]文本`

- `emotion` = EmotionProfilesV4 九选一（neutral/happy/laughing/angry/sad/crying/shy/tease/cuddle）+ 强度（weak/normal/strong）
- `attitude` = fixedGestureBindingsByAttitude 三选一（agree 点头 / deny 摇头 / question 歪头）
- `tension` 0~1 → tensionConfig 衰减驱动（影响动作选择权重）
- 微表情补充：DriverDefs 98 个 `{emotion}_{h/l/n}_{n}` 配方按需触发
